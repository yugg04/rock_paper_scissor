

# 🎮 Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors game** built using **HTML, CSS, and JavaScript**, where the user plays against the computer with real-time results.

---



## 🧠 Overview

This project demonstrates **core JavaScript concepts** such as randomization, event handling, and DOM updates by implementing a classic game.

---

## ⚙️ Features

* 🧑‍💻 User vs Computer gameplay
* 🎲 Random computer choices
* ⚡ Instant result display (Win / Lose / Draw)
* 🎨 Clean and responsive UI
* 🚫 No external libraries (pure JavaScript)

---

## 🛠 Tech Stack

* **HTML** — Structure
* **CSS** — Styling
* **JavaScript** — Game logic & DOM manipulation

## 📌 Game Logic (Simplified)

* User selects: Rock / Paper / Scissors
* Computer generates a random choice
* Rules applied:

  * Rock beats Scissors
  * Scissors beats Paper
  * Paper beats Rock
* Result displayed instantly

---

## 📌 Limitations

* No score tracking system
* No animations or advanced UI
* No persistence (game resets on refresh)
